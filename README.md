# MD SCANNER

Application Android tout-en-un de numérisation et de gestion documentaire, éditée par **MarcelAlle.Dev**.

MD SCANNER transforme un smartphone en outil professionnel : scanner de documents, OCR, boîte à outils PDF, QR codes et codes-barres, bibliothèque documentaire locale et coffre-fort chiffré.

> **État : développement en cours.** Ce README est complété au fil de l'avancement ; la section « État d'avancement » fait foi.
